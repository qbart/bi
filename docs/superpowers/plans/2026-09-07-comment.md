# Comment Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `gcc` / `gc{motion}` / visual `gc` toggle line comments using the language's own marker, with commentary's all-or-nothing rule.

**Architecture:** `Operator::Comment` joins the capture-nothing, always-linewise operator family (`Indent`, `Reflow`, `Reindent`) so every piece of machinery — motions, doubling, counts, `.`, visual — comes for free. The toggle itself is one pure buffer method `Buffer::comment_rows(first, last, marker)` (one edit, one undo, cursor on the first row's first non-blank), and the marker comes from the existing `syntax::line_comment(filetype)`.

**Tech Stack:** Rust; existing `Operator`/`Action::Operate`/`OperateSelection`, `Buffer::indent_rows` as the model, `syntax::line_comment`.

**Spec:** `docs/specs/comment.md`

## Global Constraints

- **One decision per range** (commentary): every non-blank line already commented → uncomment all; else comment all. Blank lines skipped and neutral. `gc gc` is a no-op for any range.
- **Comment** = insert `marker + " "` at the range's MINIMUM indent column (display columns). **Uncomment** = remove the marker and ONE following space if present, wherever it sits after the indent.
- **One edit, one undo step**, cursor lands on the first row's first non-blank (`indent_rows`'s shape).
- **Marker from `syntax::line_comment(filetype)` only**; `None` (CSS/JSON/markup/no filetype) → status `no line comment for <ft>` (or `no filetype`), no change. Line comments only.
- `gc` is a `g`-prefixed operator exactly like `gq`: `gcc` and `gcgc` are the doubled forms, `{count}gcc`, `.` repeats, visual `gc`. Names table: `comment`.
- House style; TDD; `cargo test` + `cargo clippy --all-targets` clean per commit; short commits, no AI trailers; master.
