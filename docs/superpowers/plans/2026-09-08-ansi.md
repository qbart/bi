# Escape Sequences in Text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A coloured `:!` build log can no longer paint the terminal: a job's escape sequences are stripped in the core, and the screen draws every control character as `^X` instead of executing it.

**Architecture:** One pure function `shell::sanitize` strips ANSI/C0 from job lines before `pump_shell` and `:w !` append them. `indent::char_width` answers 2 for a control character and a sibling `indent::glyph` names the two characters to draw, so cursor math and the drawn text agree; the three cell-writing paths in `src/tui/render.rs` (`styled_line`, `render_console`, `terminal_safe`) draw through it. Filters and `:r !` stay verbatim.

**Tech Stack:** Rust 2024, ratatui 0.29 (`TestBackend` for frame tests), unicode-width 0.2.

**Spec:** `docs/specs/ansi.md` (binding; read it first). Context: `docs/specs/shell.md`, `docs/specs/transient.md`, `CLAUDE.md`.

## Global Constraints

- Core stays sans-IO and embeddable: `sanitize` and `glyph` live in `src/shell.rs` / `src/indent.rs`, never in `src/tui/`. No `std::process` outside `shell.rs`/`main.rs`/runners. `lib_boundary` tests untouched.
- Filters (`:{range}!cmd`) and `:r !cmd` are NOT sanitized (spec Rule 1).

```rust
/// A job's line as a terminal would have *shown* it, minus the colours.
///
/// `:!` has no pty, so a program that prints escape sequences is printing
/// for a terminal that is not there — and the buffer the line lands in is
/// text, which must never carry an `ESC` a screen could execute
/// (`docs/specs/ansi.md` §"Rule 1"). CSI and OSC sequences and every other
/// `ESC x` pair go; a carriage return rewinds the line, so a progress bar
/// that redrew itself keeps its final state; the other C0 controls are
/// dropped, except the tab, which is text.
pub fn sanitize(line: &str) -> String {
    let mut out = String::with_capacity(line.len());
    let mut chars = line.chars().peekable();
    while let Some(ch) = chars.next() {
        match ch {
            '\x1b' => match chars.next() {
                Some('[') => {
                    // CSI: parameter and intermediate bytes, then one final
                    // byte in 0x40..=0x7E.
                    for c in chars.by_ref() {
                        if ('\x40'..='\x7e').contains(&c) {
                            break;
                        }
                    }
                }
                Some(']') => {
                    // OSC: up to BEL or ESC \ (ST).
                    while let Some(c) = chars.next() {
                        if c == '\x07' {
                            break;
                        }
                        if c == '\x1b' {
                            if chars.peek() == Some(&'\\') {
                                chars.next();
                            }
                            break;
                        }
                    }
                }
                // Any other two-byte sequence, or a lone trailing ESC.
                _ => {}
            },
            '\r' => out.clear(),
            '\t' => out.push('\t'),
            c if c.is_control() => {}
            c => out.push(c),
        }
    }
    out
}
```

```rust
/// The two characters a control character is drawn as — `^[` for `ESC`,
/// `^A` for `0x01`, `^?` for `DEL` — or `None` when `ch` is ordinary text
/// (or a tab, which is elastic and the caller's business).
///
/// Advice from the core, not a screen contract: the terminal draws these so
/// that no byte in a buffer can ever move its cursor or change its colours
/// (`docs/specs/ansi.md` §"Rule 2"); another frontend may draw what it
/// likes, but it gets the width from the same place, so cursor and text
/// agree wherever it is drawn.
pub fn glyph(ch: char) -> Option<[char; 2]> {
    match ch {
        '\t' => None,
        '\x7f' => Some(['^', '?']),
        c if (c as u32) < 0x20 => Some(['^', char::from(c as u8 + 0x40)]),
        _ => None,
    }
}
```

```rust
pub fn char_width(ch: char) -> usize {
    use unicode_width::UnicodeWidthChar;
    if glyph(ch).is_some() {
        return 2;
    }

}
```

```rust
/// `text` as cells: tabs to the option's stops, every other control
/// character as its `^X` glyph, so nothing a buffer holds can reach the
/// terminal as a byte it would execute. `col` runs across a row's segments
/// so the stops land where the buffer view would put them.
fn cells(text: &str, col: &mut usize, tab: usize) -> String {
    let tab = tab.max(1);
    let mut out = String::with_capacity(text.len());
    for ch in text.chars() {
        if ch == '\t' {
            let n = tab - (*col % tab);
            out.extend(std::iter::repeat_n(' ', n));
            *col += n;
        } else if let Some([a, b]) = glyph(ch) {
            out.push(a);
            out.push(b);
            *col += 2;
        } else {
            out.push(ch);
            *col += char_width(ch);
        }
    }
    out
}
```
