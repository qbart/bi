# `bi gen struct` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bi gen struct` reads `.bischema`/`.bidata` files and writes the schema's types, defaults and ids as C, C++, Go, Rust, C3 or Lua, steered by a TOML `.bimapping`.

**Architecture:** A language-neutral `Model` is built once from the parsed schemas, data and mapping (names already cased and checked for the target language, defaults fully resolved, dependency order and boxed cycles computed); six `Backend`s turn one `Unit` into text; a `write` step with an `Ask` trait applies the overwrite policy. Library in `src/codegen/structs/`, disk and prompts only in `main.rs`.

**Tech Stack:** Rust 2024, `serde_json` (already), `toml_edit` (already) for the mapping, `std::io::IsTerminal` for the tty check. No new dependencies.

**Spec:** `docs/specs/gen-struct.md` (and `docs/specs/bi-format.md` for the input format).

## Global Constraints

- No module reachable from `lib.rs` may name `ratatui` or `crossterm` (`tests/lib_boundary.rs`).
- Generated text is deterministic: no timestamps, no bi version; imports sorted; types in schema order except C/C++/C3 which use dependency order.
- Every generated file starts with `// generated by \`bi gen struct\` from <schema file name> — do not edit` (Lua: `--`, C: `//` is fine in C99).
- Commit messages: short, no Co-Authored-By, straight to `master`, pushed.
- `rustfmt.toml` style: `cargo fmt` before every commit; `cargo test` green.
- Diagnostics reuse `bi::props::Diagnostic` (`error`/`warning`), messages prefixed with the file path by the caller.

## Shared interfaces (every task uses these exact names)

```rust
// src/codegen/structs/mod.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Lang { C, Cpp, Go, Rust, C3, Lua }
impl Lang {
    pub const ALL: [Lang; 6];
    pub fn parse(s: &str) -> Option<Lang>;      // "c" "c++" "cpp" "go" "rust" "c3" "lua"
    pub fn name(self) -> &'static str;          // "c" "cpp" "go" "rust" "c3" "lua" — the TOML key
    pub fn ext(self) -> &'static str;           // "h" "hpp" "go" "rs" "c3" "lua"
}
pub struct Request {
    pub lang: Lang,
    pub pkg: Option<String>,
    pub inputs: Vec<(PathBuf, String)>,         // path + text, in command-line order
    pub mappings: Vec<(PathBuf, String)>,
    pub dir_name: String,                       // -o's last component; Go's fallback package
}
pub struct OutFile { pub path: PathBuf, pub text: String }   // path relative to -o
pub struct Output { pub files: Vec<OutFile>, pub notes: Vec<Diagnostic> }
/// `read` fetches a schema a data file points at that is not among inputs.
pub fn generate(req: &Request, read: &mut dyn FnMut(&Path) -> Result<String, String>)
    -> Result<Output, Vec<Diagnostic>>;

pub struct Context<'a> { pub pkg: Option<&'a str>, pub mapping: &'a LangMapping, pub dir_name: &'a str }
pub trait Backend {
    fn unit(&self, unit: &Unit, model: &Model, cx: &Context) -> String;
    fn support(&self, model: &Model, cx: &Context) -> Option<String>;   // None when model.builtins is empty
}
pub const SUPPORT_STEM: &str = "bi_types";
```

// src/codegen/structs/mapping.rs
#[derive(Debug, Clone, Default, PartialEq)]
pub struct External { pub spelling: String, pub import: Option<String>, pub default: Option<String> }
#[derive(Debug, Clone, Default, PartialEq)]
pub struct Generics { pub list: Option<String>, pub optional: Option<String>, pub reference: Option<String> }
#[derive(Debug, Clone, Default, PartialEq)]
pub struct LangMapping {
    pub imports: Vec<String>,
    pub types: BTreeMap<String, External>,
    pub generics: Generics,
    pub names: Vec<(String, String)>,      // shared [names] first, then this language's
    pub header: Option<String>,
    pub prefix: Option<String>,
    pub derive: Option<Vec<String>>,
}
#[derive(Debug, Clone, PartialEq)]
pub struct Mapping { pub ids: bool, pub names: Vec<(String, String)>, pub langs: BTreeMap<Lang, LangMapping> }
impl Mapping {
    pub fn parse(text: &str) -> Result<Mapping, Vec<Diagnostic>>;  // errors carry "line N: " prefix
    pub fn merge(&mut self, later: Mapping);                       // later wins per key
    pub fn for_lang(&self, lang: Lang) -> LangMapping;             // shared names prepended
}

// src/codegen/structs/model.rs
pub enum Builtin { Rgb, Rgba, Curve, Gradient, Ref }     // Builtin::ALL in this order
pub enum Ty {
    Bool, Int(IntKind), F32, F64, Str, Rgb, Rgba, Curve, Gradient,
    Named(String),                       // wire name of a schema type; look up via model.type_named
    List(Box<Ty>),
    Optional(Box<Ty>, bool),             // bool: boxed (closes a cycle)
    Ref(String),                         // wire name of the target struct
}
pub struct EnumValue { pub wire: String, pub name: String }
pub struct Id { pub wire: String, pub name: String }
pub struct Field {
    pub wire: String, pub name: String, pub ty: Ty,

    pub doc: Option<String>, pub range: Option<String>,   // "0..999", "0..1 step 0.01", "1.."

}
pub enum TypeKind { Struct { fields: Vec<Field>, ids: Vec<Id> }, Enum { values: Vec<EnumValue> } }
pub struct Type { pub wire: String, pub name: String, pub doc: Option<String>, pub kind: TypeKind, pub external: Option<External> }
pub struct Unit { pub stem: String, pub source: String, pub types: Vec<Type>, pub order: Vec<usize> }

    pub fn type_named(&self, wire: &str) -> Option<&Type>;
    pub fn spelling(&self, wire: &str) -> &str;   // external spelling or the cased name
}

### Task 5: The model

**Files:**
- Create: `src/codegen/structs/model.rs`, `src/codegen/structs/fixture.rs`
- Test: inline

**Interfaces:** As in *Shared interfaces*. Build steps, in order:

1. For each unit: every type → `Type` with `name = names::type_name(lang, wire)` unless `[names]` has `"Wire"` → that (then `escape`), or `mapping.types` has it → `external = Some(..)` and name = spelling. Prefix (`mapping.prefix`) is the backend's business, not the model's.
2. Fields: `name` from `[names]` `"Type.field"` else `field_name`, then `escape`; `ty` from `TypeExpr` (Optional's boxed flag set in step 5); `default = schema.field_default(f)`; `range = lit::range(..)`; `required_ref = matches!(ty, Ref) && f.default.is_none()`.
3. Enum values: `[names]` `"Enum.value"` else `enum_value_name`, then `escape`. Ids: for each data file, each instance of that type, `id_name`, in file order then instance order.
