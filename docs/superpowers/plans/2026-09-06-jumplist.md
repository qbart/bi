# Jump List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Ctrl-O` / `Ctrl-I` (and `Tab`, `''`, ``` `` ```) walk a per-window jump list across files, the way vim does, replacing today's buffer-cycling binding.

**Architecture:** A pure `Jumps` value type lives on `window::Text` beside `selections` (view state). Three existing seams record a jump before moving: `Action::Move(m)` when `m.is_jump()`, `Editor::show()` on every buffer switch, and the three in-buffer non-motion jumps (`goto_row`, `apply_goto`, `jump_source_window`). The walk itself (`Ctrl-O`/`Ctrl-I`) moves without recording. Entries are char offsets remapped through edits in the same `drain_edits` pass that remaps unfocused selections.

**Tech Stack:** Rust, existing `Motion`/`Action`/`Editor` machinery; no new crates.

**Spec:** `docs/specs/jumplist.md`

## Global Constraints

- **Per window, capped at 100, oldest dropped first.** Never crosses windows.
- **Jump motions are exactly:** `FirstLine`, `LastLine`, `Line(_)`, `Search{..}`, `Found(_)`, `MatchingBracket`, `Paragraph{..}`; plus every buffer switch through `Editor::show`; plus `goto_row`, `apply_goto` (same-buffer target), `jump_source_window`. Not jumps: `h j k l w b e 0 ^ $ f t ; ,` and scrolling. `:s`/`:g` are NOT jumps (recorded deviation).
- **Recording rules:** push the position being *left*, before the move; a push equal to the top entry is a no-op; a push while walking (`at < len`) truncates the forward half first; `Ctrl-O` from the end first pushes the current position so `Ctrl-I` returns to it; the walk (`Ctrl-O`/`Ctrl-I`/`''`) never pushes except that end-of-list case.
- **Operators do not jump:** a motion under `d`/`y`/`c` is a range, not a move — only `Action::Move` records.
- **`Tab` is `Ctrl-I`** (same byte); it becomes jump-forward; buffer-next keeps `:bn`, `gb`, `Ctrl-^`, `Ctrl-Tab`.
- **Entries follow the text** through `Edit::map` in `drain_edits`, like unfocused selections. Entries whose buffer is closed are skipped on the walk and pruned on the next touch; offsets are clamped to the buffer's length when landing.
- **Comment style:** dense, literate, WHY — match `src/window.rs` / `src/editor.rs`. Every public item documented.
- **TDD:** failing test first; `cargo test` + `cargo clippy --all-targets` clean before each commit; short commit messages, no AI trailers (CLAUDE.md rule 5); straight to master.

**Interfaces:**
- Consumes: `crate::buffer::BufferId`, `crate::buffer::Edit` (has `pub fn map(&self, at: usize) -> usize`).
- Produces:
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq)]
  pub struct Jump { pub buffer: BufferId, pub at: usize }
  #[derive(Debug, Clone, Default, PartialEq, Eq)]
  pub struct Jumps { entries: Vec<Jump>, at: usize }   // at == entries.len() when not walking
  pub const CAP: usize = 100;
  impl Jumps {
      pub fn push(&mut self, jump: Jump);              // truncate forward half; dedupe top; cap
      pub fn back(&mut self, from: Jump, count: usize) -> Option<Jump>;   // Ctrl-O
      pub fn forward(&mut self, count: usize) -> Option<Jump>;             // Ctrl-I
      pub fn last(&mut self, from: Jump) -> Option<Jump>;                  // ''
      pub fn remap(&mut self, buffer: BufferId, edits: &[Edit]);
      pub fn prune(&mut self, open: impl Fn(BufferId) -> bool);
      pub fn is_walking(&self) -> bool;
      pub fn len(&self) -> usize; pub fn is_empty(&self) -> bool;
  }
  ```
  `back(from, n)`: if `!is_walking()` push `from` first (the end-of-list rule), then step `at` back `n` (saturating at 0; `None` if it could not move at all) and return `entries[at]`. `forward(n)`: step `at` forward `n` capped at `len-1`; `None` at the end; when `at` reaches `len-1` the list is at its newest entry (still "walking" until a push resets). `last(from)`: the position before the latest jump = `entries.last()` when not walking; it pushes `from` and returns that entry (so `''` `''` toggles); walking → same as `back(from,1)`.
