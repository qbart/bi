# Shell Commands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `:!cmd` as a background job streaming into the debugger's Console pane, plus synchronous filters `:{range}!cmd`, `:r !cmd`, `:w !cmd`, with `:stop`, `:!!`, and `%`/`#` expansion.

**Architecture:** `src/shell.rs` is a pure core (`Job` state, the `expand` for `%`/`#`, a `Spawn` seam with a `Slot` the reader thread fills) mirroring the `:lsp install` handoff: a thread pushes lines into an `Arc<Mutex<..>>` slot and rings the waker; `pump_shell` in `settle` drains it into the Console. Filters bypass all of that and go through the existing `fmt::Run` runner synchronously, like `:format`. The editor never spawns; `set_shell_spawner`/`set_shell_waker` cross the lib boundary like the DAP pair.

**Tech Stack:** Rust std process/thread; existing `fmt::Run`, `DapConsole`, `Scope`/`scope_rows`, ex parser.

**Spec:** `docs/specs/shell.md`

## Global Constraints

- **Filters are SYNCHRONOUS through `fmt::Run`** (the 5 s guard, first-stderr-line-on-failure, buffer untouched on failure). **Bare `:!` is a background JOB** with no timeout, stopped only by `:stop` / pane `Ctrl-C` / pane `x` / quit.
- **One job at a time**: a second `:!` while one runs → status `! is running <cmd> — :stop it first`, no spawn.
- **Job output reuses `DapConsole`** (2000-line bound, existing renderer/keys); `:!` opens the Console if none is shown, exactly as `:debug console` does; first line `$ <cmd>`; stderr lines prefixed `! `; trailer `exited <n>` / `killed`; the status line says `! exited <n>` / `! killed`.
- **stdin closed at spawn.** Non-UTF-8 output decoded lossily.
- **Stop = SIGTERM, ~2 s, SIGKILL**, then reap. Quit kills a running job (`shutdown_shell` beside `shutdown_lsp`/`shutdown_dap`).
- **`!` inside a command is literal; `:!!` repeats the last `:!` job.** `%` → current file path, `#` → alternate; `\%`/`\#` literal.
- **The editor never spawns**: `shell::Spawn` trait + `ProcessSpawn` in `main.rs`; a `fake` for tests. Reader threads only push + wake; all interpretation in `settle`.
- **House style** (dense, literate, WHY); TDD; `cargo test` + `cargo clippy --all-targets` clean before each commit; short commit messages, no AI trailers; straight to master.

```rust
/// `%` → the current path, `#` → the alternate; `\%`/`\#` literal. `!` untouched.
pub fn expand(cmd: &str, current: Option<&str>, alternate: Option<&str>) -> Result<String, String>;
  // Err when `%`/`#` is used and that path is None: "no file name for %" / "no alternate file for #"
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Line { Out(String), Err(String) }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Exit { Code(i32), Signal, Killed }
/// What the reader threads fill and `pump_shell` drains. Lines in arrival order; `exit` once.
#[derive(Clone, Default)]
pub struct Slot(Arc<Mutex<SlotInner>>);   // SlotInner { lines: Vec<Line>, exit: Option<Exit> }
impl Slot { pub fn push(&self, l: Line); pub fn finish(&self, e: Exit); pub fn drain(&self) -> (Vec<Line>, Option<Exit>); }
pub trait Handle: Send { fn kill(&mut self); /* SIGTERM, ~2s, SIGKILL, reap */ fn is_running(&mut self) -> bool; }
pub trait Spawn { fn spawn(&self, cmd: &str, cwd: &Path, slot: Slot, wake: Arc<dyn Fn() + Send + Sync>) -> Result<Box<dyn Handle>, String>; }
pub struct ProcessSpawn;  // `sh -c cmd`, stdin null, stdout+stderr piped, two reader threads, a waiter thread that calls finish()
pub struct Job { pub cmd: String, pub slot: Slot, pub handle: Box<dyn Handle>, pub exit: Option<Exit> }
#[cfg(test)] pub mod fake { pub struct FakeSpawn { pub spawned: Arc<Mutex<Vec<(String, Slot)>>>, pub killed: Arc<Mutex<usize>> } + a FakeHandle }
```
