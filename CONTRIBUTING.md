# Contributing

What bi is and where it is headed lives in the [README](README.md) and in
[docs/specs](docs/specs).

## Bug reports

Very welcome. Say what you did, what happened, and what you expected —
version and platform included. Best of all is a reproducible environment as a
GitHub repo I can clone: the files that trigger it and the steps to follow.
That lets me download your exact case, debug it, and release a fix.

## Pull requests

Probably not accepted. bi is a personal project with its direction written
down in [docs/specs](docs/specs), and reviewing code costs exactly the time
the project exists to save. If you think something is genuinely missing, open
an issue first; feature requests may be declined without much ceremony, and
that is nothing personal.
